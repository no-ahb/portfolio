Projects

Choose Art projects or Portfolio projects. Edit descriptions and page text, or create a project. Keep Draft enabled until it is ready.

03

Open Page copy for homepage introductions, film-scoring credits, and the text in custom portfolio presentations.

Saving publishes your changes

Select no-ahb / website and the main branch in the editor. Each save starts a rebuild of both sites. Allow a few minutes, then refresh the page you edited.

Check publishing progress

First-time connection

Sign in to Pages CMS with the GitHub account that owns your website. When prompted, install the Pages CMS GitHub app for the website repository. Open that repository and select main. Your editing sections will appear automatically.
